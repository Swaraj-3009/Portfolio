What it is

A full-stack portfolio app. The frontend talks to a Java Servlet backend that stores everything in MySQL.

For visitors

Register or continue as a guest to view the developer profile and the full portfolio. Registered users can edit their own account details.

For the owner

The admin signs in separately to manage the profile, education, skills and projects shown on the portfolio.
